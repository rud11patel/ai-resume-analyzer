# Data Models Specification (Phase 3 Preparation)

This directory will contain the Mongoose schemas and models for the AI Resume Analyzer application.
Full schema implementation takes place in Phase 3. The planned architecture and relationships are defined below:

---

## 1. User Model (`User.js`)
Represents registered users/candidates.

```javascript
{
  _id: ObjectId,
  email: { type: String, required: true, unique: true, lowercase: true, index: true },
  passwordHash: { type: String, required: true },
  fullName: { type: String, required: true },
  role: { type: String, enum: ['user', 'admin'], default: 'user' },
  createdAt: { type: Date, default: Date.now },
  updatedAt: { type: Date, default: Date.now }
}
```

---

## 2. Resume Model (`Resume.js`)
Stores parsed resume metadata, uploaded file references, extracted text, and skills.

```javascript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true, index: true },
  title: { type: String, required: true },
  fileName: { type: String, required: true },
  fileUrl: { type: String, required: true },
  fileSize: { type: Number },
  mimeType: { type: String },
  rawText: { type: String, required: true },
  parsedData: {
    skills: [{ type: String, index: true }],
    experienceYears: { type: Number },
    education: [{
      institution: String,
      degree: String,
      year: Number
    }],
    workExperience: [{
      company: String,
      role: String,
      duration: String,
      responsibilities: [String]
    }]
  },
  createdAt: { type: Date, default: Date.now },
  updatedAt: { type: Date, default: Date.now }
}
```

---

## 3. JobDescription Model (`JobDescription.js`)
Stores target job vacancies, required skills, and expectations.

```javascript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true, index: true },
  title: { type: String, required: true },
  company: { type: String },
  rawText: { type: String, required: true },
  parsedRequirements: {
    requiredSkills: [{ type: String, index: true }],
    optionalSkills: [{ type: String }],
    experienceRequiredYears: { type: Number },
    responsibilities: [String]
  },
  createdAt: { type: Date, default: Date.now },
  updatedAt: { type: Date, default: Date.now }
}
```

---

## 4. AnalysisResult Model (`AnalysisResult.js`)
Stores the comparison analysis output generated by the AI engine.

```javascript
{
  _id: ObjectId,
  userId: { type: ObjectId, ref: 'User', required: true, index: true },
  resumeId: { type: ObjectId, ref: 'Resume', required: true, index: true },
  jobDescriptionId: { type: ObjectId, ref: 'JobDescription', required: true, index: true },
  compatibilityScore: { type: Number, required: true, min: 0, max: 100 },
  matchedSkills: [{ type: String }],
  missingSkills: [{ type: String }],
  suggestedImprovements: [{
    category: { type: String, enum: ['skills', 'experience', 'format', 'impact'] },
    recommendation: { type: String },
    priority: { type: String, enum: ['high', 'medium', 'low'] }
  }],
  aiSummary: { type: String },
  processingTimeMs: { type: Number },
  createdAt: { type: Date, default: Date.now }
}
```

---

## Entity Relationship Overview
- **User (1) ────< (N) Resume**
- **User (1) ────< (N) JobDescription**
- **Resume (1) ────< (N) AnalysisResult**
- **JobDescription (1) ────< (N) AnalysisResult**
