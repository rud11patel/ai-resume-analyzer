# Client Pages Directory

This directory will contain the page route components for the AI Resume Analyzer application (to be implemented in subsequent phases):

- `LandingPage.jsx`: Public landing page showcasing features and call-to-actions.
- `DashboardPage.jsx`: Main user dashboard showing uploaded resumes and recent analysis results.
- `UploadPage.jsx`: Drag-and-drop resume upload and job description entry page.
- `AnalysisResultPage.jsx`: Comprehensive analysis report view (scores, missing skills, suggestions).
